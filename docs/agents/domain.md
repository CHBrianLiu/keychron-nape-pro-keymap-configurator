# Domain Docs

This repository uses a single-context layout.

## Before exploring

- Read `GLOSSARY.md` at the repository root.
- Read relevant decisions in `docs/adr/`.
- For existing milestone designs, consult `docs/design/`;
  source-backed findings live in `docs/research/`.

If the glossary or ADRs are absent, proceed silently.
Domain modeling creates them when terms or decisions are resolved.

## Vocabulary

Use glossary terms in issue titles, proposals, hypotheses, and tests.
Respect explicitly discouraged synonyms.

If a needed concept is missing, reconsider the term or flag the gap
for domain modeling.

## Decisions

Surface conflicts with existing ADRs explicitly rather than silently
overriding them. Name the ADR and explain why it may need reopening.
