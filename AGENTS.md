## Agent skills

### Issue tracker

Use local Markdown issues under `.scratch/<feature>/`.
Before creating specs or creating, fetching, or updating tickets, read
`docs/agents/issue-tracker.md`.

### Triage labels

Before triaging issues, read `docs/agents/triage-labels.md`
for the five default roles.

### Domain docs

Single-context layout: `GLOSSARY.md` and `docs/adr/`.
Before exploring the codebase or proposing domain changes, read
`docs/agents/domain.md`.
